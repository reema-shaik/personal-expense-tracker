# personal-expense-tracker

Project Overview

The Personal Expense Tracker is a Python-based application developed to manage daily income and expenses. It helps users record transactions and understand their spending habits.

Features

- Add Income
- Add Expenses
- View Today's Transactions
- Monthly Income and Expense Summary
- Category-wise Summary
- Search Transactions
- Save Transaction Details in CSV File
- Automatic Date Generation

Technologies Used

- Python
- CSV Module
- Datetime Module

How to Run

1. Download or clone this repository.
2. Open the project in Python or Pydroid 3.
3. Run "expense_tracker.py".
4. Select an option from the menu.
5. Enter transaction details.

Project Files

- "expense_tracker.py" – Main Python source code.
- "personal-expense-tracker-output.pdf" – Project output screenshots.
- "README.md" – Project documentation.

Output

The application displays transaction details, monthly summaries, and category-wise summaries.

Developer

Developed as a Python project to practice file handling, functions, CSV operations, and date handling.
